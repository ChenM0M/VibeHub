# Agent 配置 PR 整合说明（2026-09-23）

本候选整合 PR #6–#32。它用于整体审查与验收，尚未合入 main，也不是新 Release。

## 使用变化

- OpenCode 的 JSONC 注释与未受管理字段在修改受管理字段时保留；发现配置但解析失败时，页面保留文件和错误信息。
- 支持 `XDG_CONFIG_HOME`、`OPENCODE_CONFIG` 和 `OPENCODE_CONFIG_DIR`。自定义路径使用绝对路径；修改宿主环境变量后重新启动 VibeHub。WSL 路径属于所选发行版。
- OpenCode 空配置可初始化。选中的配置文件随启动环境传递，避免启动到另一个文件。
- 切换 Agent、运行环境、Profile 或刷新时，未保存的草稿提供保存、放弃和取消选项。保存失败不会继续切换。带草稿启动或设置默认项前先保存。
- 模型默认项包含 Provider 身份；编辑其他模型不应改变默认模型。禁用 OpenCode 模型保留其配置，通过原生过滤列表控制可用性。
- 未声明的 reasoning、工具与模态能力保持未知。能力声明不代表接口实测通过。
- 可编辑模型输入/输出模态、Token 限制、变体 JSON 参数和原生支持的思考参数。Token 限制全部为空时继承；显式覆盖需要正整数 context 与 output，input 可选。
- 模型编辑器受视口高度限制，可滚动访问全部变体、校验错误和应用按钮。
- 配置来源预览显示所选文件与变体的受管理值、未知来源及未保存提示；它不是所有外部配置层完全合并后的运行时配置。
- 复制启动指令失败会显示错误和可手动复制的指令。

## 升级与回退

此候选未修改版本号、执行发布或安装应用。审查通过后，仍须按仓库发布流程构建并验收指定 artifact/hash。

试用时先用 disposable home/config，保留原始配置与保存产生的备份。需要回退配置时使用页面受限恢复入口和当前 revision；遇到外部修改冲突应重新读取、核对差异后再操作，不直接覆盖新内容。不要删除 V3 日志或投影来回退配置。回退应用应恢复之前确认的安装包；不能用源码回退替代配置恢复。

## 凭据与边界

API Key 按既有授权写入本机 Agent 原生配置；回读、预览与错误展示须保持脱敏。预览不显示 credential 内容，复制的启动指令只绑定配置路径。不要将真实 Key 放入测试 fixture、PR、日志或截图。
