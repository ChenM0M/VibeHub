# V3 usage source capabilities

Date: 2026-07-12

This document is the production capability contract for the M1 usage surfaces. VibeHub reads supported sources locally and read-only. It never estimates an actual bill from static model prices, derives quota from tokens, or assigns usage to a project without a stable path-bearing source field. Unsupported values remain unavailable; they are not displayed as zero and do not enter aggregates.

## Field-level rules

- **Token:** aggregate only locally recorded token counters with an exact/canonical project path or the explicitly warned unique same-name fallback implemented for Codex/OpenCode. Cache-inclusive and non-cached totals remain distinct in the read model.
- **Cost:** only a source-recorded value can be exposed. It is never converted into an actual subscription bill. The M1 cost metric remains `不可用` because the cross-source aggregate is not an authoritative bill.
- **Quota:** unsupported for every current source. VibeHub does not infer it from tokens or cost.
- **Model/tool activity:** shown only when the source record contains model or tool-use metadata. Missing values remain unknown.
- **Phase distribution:** unsupported for external agents because their local records have no stable mapping to VibeHub phases. The original M1 phase surface remains and says `unsupported`.
- **Sessions:** only safe metadata is returned: identifier, sanitized title, model names, counts, timestamps/duration, status and recorded usage. Prompt/message bodies are not returned to the UI.
- **Freshness:** based on the newest source observation with a 900-second stale threshold. Missing timestamps produce `unknown`/`partial`, never synthetic freshness.
- **Source completeness:** `complete`, `partial`, `empty`, or `unavailable` reflects supported readers. Explicit unsupported sources are visible as source summaries but never reduce recorded token totals or source count.

## Unsupported-source UI contract

`LocalAgentUsageOverview` includes explicit `claude_app` and `cursor` summaries with `status: "unsupported"`, `available: false`, no cost, no sessions, and zero-valued transport counters that are never rendered as numeric usage or included in aggregates. The M1 tool distribution renders these rows as `unsupported`; the total token and cost cards use a dash/`不可用` when no authoritative value exists. This distinguishes unsupported capability from a supported source that was read successfully and had no matching records (`empty`).

## Security boundary

Production readers do not modify any source. Tests use synthetic fixtures or isolated temporary databases/transcripts. Real local smoke, when explicitly run, is read-only and asserts metadata/counts only; evidence must not contain prompts or message bodies.
