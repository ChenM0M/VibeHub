# VibeHub 3.3.12

## 用户可见变化

- OpenCode `.json` 配置支持 JSONC 注释；修改受管字段时注释与未管理字段完整保留，发现配置但解析失败时保留文件与结构化错误。
- 新增配置路径发现：支持 `XDG_CONFIG_HOME`、`OPENCODE_CONFIG`、`OPENCODE_CONFIG_DIR`（自定义路径须为绝对路径），按所选运行时（含 WSL 发行版）读取；修改宿主环境变量后需重启 VibeHub。空配置可初始化，启动时绑定所选配置文件。
- 脏草稿保护：切换 Agent、运行环境、Profile、刷新或关闭编辑上下文时提供保存、放弃与取消；保存失败不会继续切换；带草稿启动或设置默认项前先保存。
- 模型能力保持诚实：未声明的 reasoning、工具与模态能力显示为未知，不以猜测充当实测。可编辑输入/输出模态、上下文与输出 Token 上限、变体 JSON 参数与原生思考参数；Token 上限全部为空时继承，显式覆盖需要正整数 context 与 output，input 可选。
- 生效配置预览显示所选文件与变体的受管值、未知来源与未保存提示；它不是所有外部配置层完全合并后的运行时配置，也不显示凭据内容。
- 模型默认项包含 Provider 身份，编辑其他模型不再改变默认模型；禁用 OpenCode 模型保留其配置，通过原生过滤列表控制可用性；复制启动指令失败会显示错误与可手动复制的指令。
- Windows launcher 保留原生 argv 参数边界并返回真实启动结果；交互式 Agent 使用可见控制台，后台探测保持静音。

## 升级与回退

本版本不改动你的既有配置结构；保存前会自动生成备份。建议先用 disposable home/config 试用，保留原始配置。遇到外部修改冲突时应重新读取、核对差异后再操作，不要直接覆盖新内容；不要删除 V3 日志或投影。回退应用请使用先前确认的安装包，不能用源码回退替代配置恢复。

## 凭据与边界

API Key 按既有授权写入本机 Agent 原生配置；回读、预览与错误展示保持脱敏。预览不显示 credential 内容，复制的启动指令只绑定配置路径。不要将真实 Key 放入测试 fixture、issue、日志或截图。

## 验证边界

本版本已在本地通过 `release:check`、前端 production build、V3 contracts、Rust formatting、Rust workspace 测试（`--locked`，desktop 113 passed / 3 个既有 ignored、core 472、adapters 10）、真实构建 CLI 的 MCP contract test、`git diff --check` 与 macOS bundle strict codesign 检查；三平台 CI 门禁由 Release workflow 在发布 tag 上执行。

Windows 原生验收（A07、E07、F07–F10、G05）仍需在发布后使用本版本 Windows artifact 与 `SHA256SUMS-windows-x64.txt` 在 Windows 10/11 主机或可信 VM 完成，不得以 macOS/CI 证据替代；浏览器开发 fixture 的界面行为证据不证明原生配置保存或实际 Agent 启动。
