# VibeHub 3.4.3

修复 Linux AppImage 在其他用户或沙箱中无法启动的问题。3.4.2 已修复图标断链，但 AppImage Catalog 的真实复测发现内部启动器 `AppRun.wrapped` 使用 `0770` 权限，非所有者无法执行。本版在打包前校验官方启动器内容，并设置可移植的 `0755` 权限。

发布检查同时验证最终包内所有目录和文件的读取/执行权限，并以 `nobody` 用户启动 root 所有的解包目录，确认真实英文界面能够显示。保留 3.4.2 的图标、桌面分类和搜索提示语修复。

Fixes AppImage startup in sandboxes and under other users by packaging the verified official launcher with permissions `0755`. Release checks now reject restricted file permissions and verify the English UI as an unprivileged user against a root-owned AppDir.

目录收录以 [上游 PR](https://github.com/AppImage/appimage.github.io/pull/8873) 的实际复测结果为准。Windows 同发布产物的 A07、E07、F07–F10、G05 原生验收仍待发布后手测，不能用 CI 构建代替。签名状态以各产物实际信息为准。
