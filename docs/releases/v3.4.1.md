# VibeHub 3.4.1

修复 Windows 文件打开的错误反馈。此前仅启动 Explorer，文件消失或默认应用打开失败时仍可能返回成功；现在检查目标是否存在，并使用 Windows Shell 的实际调用结果，将失败显示在界面中。文件定位同样拒绝已经消失的目标。

保留 3.4.0 的 Agent 原生读取、12 个常用工具、稳定请求恢复和严格权限校验。此次没有改变工作流事实、绑定或验收门禁。

该问题来自 3.4.0 精确发布安装包的 Windows 原生验收；修复前后结果、产物哈希和仍未验证的项目见 [验收记录](https://github.com/ChenM0M/VibeHub/blob/main/docs/v3/agent-native-mcp-redesign.md)。签名状态以产物实际信息为准。
