# VibeHub 3.3.6

## 用户可见变化

- Windows 上的 OpenCode 配置发现现在会分别检查 XDG `.config/opencode` 和 legacy `AppData/Roaming/opencode` 路径；其中一个候选不可读或格式错误时，仍会继续使用其他可用配置。
- 配置页会显示错误码、出错路径、具体原因和恢复建议，不再只显示一条无法判断原因的路径。
- WSL/runtime 探测改为静默启动，切换 OpenCode、Claude Code 或 Codex 配置时不会因为探测过程主动弹出可见的 cmd/PowerShell 窗口。
- 保存 OpenCode JSON/JSONC 时保留注释、未知字段和完整 variant 对象；只修改其他字段不会把复杂 variant 重置为空对象，也支持明确清空 variant。

## 验证边界

本版本已通过 OpenCode/storage focused Rust tests、Tauri variant boundary test、前端构建、V3 contracts、i18n、Agent Profiles contract、MCP contract、CLI 构建、Rust 格式和补丁卫生检查。Windows 原生 GUI 的无黑框、reparse/junction、真实页面交互以及同一发布产物的验收，仍需在发布后使用本版本 Windows artifact 在 Windows 10/11 主机或可信 VM 完成；macOS/CI 证据不替代该手测。
