# VibeHub 3.4.2

修复 Linux AppImage 的图标打包问题：之前 `.DirIcon` 指向构建机器上的绝对路径，下载后无法解析，导致 AppImage 目录检查失败。本版升级打包器，补全桌面开发工具分类，并在发布前对最终 AppImage 检查入口、图标链接和真实窗口启动。

搜索框提示语现在跟随界面语言，使用已有的英文、简体中文和繁体中文翻译。

Fixes the broken icon link in the Linux AppImage, adds the desktop development category, and verifies the final AppImage structure and window startup before release. The project search placeholder now follows the selected interface language.

AppImage Catalog 的收录状态以 [上游 PR](https://github.com/AppImage/appimage.github.io/pull/8873) 对本版的实际复测结果为准。Windows 同发布产物的 A07、E07、F07–F10、G05 原生验收仍待发布后手测；构建成功不代替这些验收。签名状态以各产物实际信息为准。
