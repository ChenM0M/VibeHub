# VibeHub 3.3.5

## 用户可见变化

- 修复 v3.3.4 引入的归档回归：带有残留阻塞事实（遗留或无 terminal result 的 Session、stale projection、未关闭 finding、blocked PlanNode）的已确认完成任务，之前被改判为 `blocked`，导致已归档任务重新回到 active 列表，以及「完成并归档」后在归档视图里找不到该任务。现在真正确认完成的任务保持终态 `completed` 并留在归档，残留阻塞只作为诊断展示在归档摘要与时间线中。
- 发布流程不再强制要求界面截图：发布说明不再必须附带 1600×1000 截图，减少发版门槛。

## 验证边界

当前候选已通过前端构建、V3 contracts、MCP、Rust workspace 测试、CLI 构建与补丁卫生检查。Windows 原生启动器、文件锁、升级/回滚与卸载验收仍需在真实 Windows 10/11 环境完成；CI 构建不替代该手测。
