# VibeHub 3.3.8

## 用户可见变化

- 修复 v3.3.7 在 Windows 上的迁移回归：store format 1 → 2 的一次性兼容迁移在 Windows 上必然失败（`Access is denied`）。原因是迁移备份 `manifest.json` 与迁移标记文件的句柄未关闭就执行原子重命名；Windows 不允许重命名内部含打开句柄的目录。现在句柄在重命名前显式关闭。该失败为 fail closed：源 `events.jsonl` 与用户数据不受影响，安装本版本后重试迁移即可。
- macOS 与 Linux 行为不变。

## 验证边界

本版本已通过 `release:check`、前端构建、V3 contracts、Rust workspace 测试（`--locked`，含此前在 Windows CI 失败的全部 10 个 MCP 存储/MCP 测试）、CLI 构建、MCP contract test 与 macOS bundle strict codesign 检查；Windows CI 测试在本版本转绿。

Windows 原生验收（文件锁、原子替换、崩溃恢复、路径语义，以及同一 Release artifact/hash 的 A07、E07、F07–F10、G05 手测）仍需在发布后使用本版本 Windows artifact 在 Windows 10/11 主机或可信 VM 完成；macOS/CI 证据不替代该手测。
